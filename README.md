# Web Application — Technologies for Information Systems (TIW) A.Y. 2024/2025

Academic project developed for the **Technologies for Information Systems (Tecnologie Informatiche per il Web - TIW)** course at **Politecnico di Milano** (B.Sc. in Computer Engineering).

---

## 📌 Project Overview

This project consists of the end-to-end design and implementation of a full-stack, data-driven web application developed according to modern web architectures and usability standards. 

The application is structured into two core implementations:
1. **Pure HTML / Server-Side Architecture:** MVC architecture implemented using Java Servlets, DAO (Data Access Object) design patterns, and Thymeleaf templating for server-side HTML rendering.
2. **Rich Internet Application (RIA) / Client-Side Architecture:** Single-Page Application (SPA) architecture leveraging asynchronous communication (`Fetch API` / AJAX), JSON payloads, client-side state management, and DOM manipulation in vanilla JavaScript without external frontend frameworks.

## 🏗️ Architecture & Features

* **State & Session Management:** Stateful session handling and security filters for user authentication and authorization.
* **Database Layer:** Relational data modeling in MySQL managed via connection pools, transactions, and parameterized SQL queries to mitigate SQL injection vulnerabilities.
* **Separation of Concerns:** Strict adherence to MVC (Model-View-Controller) design principles to decouple data models, routing logic, and presentation.
* **Error & Exception Handling:** Robust validation on both client (JavaScript) and server (Java Servlets) layers with user feedback.

---

## 🛠️ Tech Stack

* **Backend:** Java, Java Servlets (Jakarta EE), JDBC
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6+), Thymeleaf
* **Database:** MySQL
* **Build & Tools:** Apache Maven, Apache Tomcat, Git & GitHub
